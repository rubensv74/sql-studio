# SQL Studio

**AI Engineering Framework for SQL Server & Azure SQL**

## Vision

SQL Studio is a Git-based engineering framework designed to develop,
optimize and maintain SQL Server assets through structured AI-assisted
sprints.

The repository is the single source of truth.

## Core Principles

-   Architecture before implementation.
-   One sprint = one complete deliverable.
-   Every optimization must be benchmarked.
-   Functional behaviour must not change unless explicitly approved.
-   Every decision is documented.
-   Git is the source of truth.

## Initial Repository Structure

``` text
SQL-Studio/
├── database/
├── diagnostics/
├── benchmarks/
├── handoffs/
├── sprints/
├── docs/
└── tools/
```

## Sprint Workflow

1.  Analyse
2.  Design
3.  Implement
4.  Benchmark
5.  Document
6.  Commit
7.  Generate SQL Handoff
